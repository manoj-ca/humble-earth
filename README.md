## Humble Earth — Project README

This README provides the necessary information to set up and maintain the website for **Humble Earth Excavation, Septic & Construction**.

### Project Overview

Humble Earth is a professional service provider in the Kootenay Lake region, specializing in site preparation, septic systems, and custom construction. This website serves as a digital portfolio and contact hub for their operations in communities such as Crawford Bay, Nelson, and Kaslo.

### Installation & Setup

1. **Extract the Files**: Unzip the `Claude HTML files.zip` archive into your project directory.
2. **Directory Structure**: Keep all HTML files in the same root folder to maintain navigation links.
3. **Local Preview**: Open `index.html` in any modern web browser to view the site.

### Usage & Deployment

* **GitHub Pages**: Push these files to a GitHub repository, go to **Settings > Pages**, and select the `main` branch as your source.
* **Editing Content**: Update business details (phone/email) in the `<footer>` section of each HTML file.
* **Styling**: Modify the CSS variables (like `--orange` or `--blue-ink`) located in the `<style>` tag at the top of each file.
