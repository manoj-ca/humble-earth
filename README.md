## Humble Earth — Project README

This README provides the necessary information to set up and maintain the website for **Humble Earth Excavation, Septic & Construction**.

### Project Overview

Humble Earth is a professional service provider in the Kootenay Lake region, specializing in site preparation, septic systems, and custom construction. This website serves as a digital portfolio and contact hub for their operations in communities such as Crawford Bay, Nelson, and Kaslo.

### Structure & Local Preview

* **`index.html`**: Main single-page site (sections for hero, reviews, interactive project planner, work galleries, services, about, service area map, and contact, plus the "Ask Humble Earth" assistant).
* **`assets/`**: Self-hosted fonts (`assets/fonts/`, `assets/css/fonts.css`), styles (`assets/css/site.css`), interactive scripts (`assets/js/site.js`), and WebP imagery (`assets/img/`).
* **`CNAME`**: Custom domain configuration (`humblebuilt.ca`) for GitHub Pages.
* **Local Preview**: Serve the repository root with any static HTTP server (or open `index.html` in a browser) to preview changes.

### Usage & Deployment

* **GitHub Pages**: Push these files to the GitHub repository, go to **Settings > Pages**, and deploy from the `main` branch.
* **Editing Content**: Update contact details, assistant answers, or section copy in `index.html` and `assets/js/site.js`.
* **Styling**: Modify the CSS custom properties (such as `--or`, `--ink`, or `--blue`) in `assets/css/site.css`.
