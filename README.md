\## Humble Earth — Project README



This README provides the necessary information to set up and maintain the website for \*\*Humble Earth Excavation, Septic \& Construction\*\*.



\### Project Overview



Humble Earth is a professional service provider in the Kootenay Lake region, specializing in site preparation, septic systems, and custom construction. This website serves as a digital portfolio and contact hub for their operations in communities such as Crawford Bay, Nelson, and Kaslo.



\### Core Capabilities



&#x20; \* \*\*Excavation \& Site Services\*\*: Building pads, driveways, utility trenching, and drainage solutions.

&#x20; \* \*\*Septic Systems\*\*: ROWP-registered installation, design coordination, and repairs.

&#x20; \* \*\*Construction \& Renovations\*\*: Cabins, additions, cedar decks, and custom interior finishing.

\### Installation \& Setup



To get this website running locally or prepare it for hosting:



1\.  \*\*Extract the Files\*\*: Unzip the `Claude HTML files.zip` archive into your desired project directory.

2\.  \*\*Directory Structure\*\*: Ensure all HTML files remain in the same root folder to maintain proper navigation links:

&#x20;     \* `index.html` (Homepage)

&#x20;     \* `about.html` (Company Philosophy)

&#x20;     \* `construction.html` (Building Services)

&#x20;     \* `excavation.html` (Site Services)

3\.  \*\*Local Preview\*\*: Open `index.html` in any modern web browser (Chrome, Firefox, Safari, or Edge) to view the site.

4\.  \*\*Dependencies\*\*: The project leverages Google Fonts (Poppins and Open Sans), so an active internet connection is required for the typography to render correctly.



\-----



\### Usage \& Deployment



\#### GitHub Deployment



To host this site on \*\*GitHub Pages\*\*:



1\.  \*\*Initialize Repository\*\*: Create a new repository on GitHub.

2\.  \*\*Upload Content\*\*: Push the four HTML files to the `main` branch.

3\.  \*\*Activate Pages\*\*:

&#x20;     \* Navigate to \*\*Settings\*\* \\> \*\*Pages\*\* in your GitHub repository.

&#x20;     \* Under "Build and deployment," select the `main` branch and click \*\*Save\*\*.

4\.  \*\*Live URL\*\*: Your site will be available at `https://\[your-username].github.io/\[repository-name]/`.



\#### Modifying Content



&#x20; \* \*\*Contact Details\*\*: To update the business phone or email, locate the `<footer>` section or the `#contact` ID in `index.html`.

&#x20; \* \*\*Styling\*\*: All CSS is contained within `<style>` tags in the `<head>` of each document. Global variables for colors (e.g., `--orange`, `--blue-ink`) are defined at the top of these blocks for easy brand adjustments.

&#x20; \* \*\*Service Areas\*\*: To add or remove served communities, edit the text within the footer grid in all four HTML files to ensure consistency.
